Advanced and technical details
  • Local & offline: The backend binds strictly to 127.0.0.1 and makes zero external network calls.
  • Authenticated encryption: Uses Argon2id (RFC 9106) key derivation and AES-256-GCM (NIST SP 800-38D) AEAD.
  • Integrity protection: Tampered bits or incorrect passwords fail authentication without leaking partial plaintext.
  • Lossless preservation: JPEG, WebP, and GIF carriers are normalized to 8-bit RGB/RGBA and saved as lossless PNG to avoid compression loss.
  • Memory sanitization: Volatile memory is wiped with secure zeroing after key derivation and encryption.
