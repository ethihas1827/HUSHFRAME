# Cryptographic Protection

This directory houses cryptographic primitives and memory security routines:
- `argon2id.c`: Passphrase-based key derivation using Argon2id (Phase 3).
- `aes_gcm.c`: Authenticated encryption with AES-256-GCM (Phase 3).
- `key_derivation.c`: High-level key derivation interfaces.
- `secure_memory.c`: Memory zeroing and memory hygiene.
- `integrity.c`: CRC-32 and payload integrity verification.
