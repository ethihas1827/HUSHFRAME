# Output Images (Created)

This folder is the designated location where all created output files and images are stored:
- Protected stego images (`stego.png`, `protected_image.png`)
- Split stego part images (`secret_part1_of_4.png`, etc.)
- Stripped / sanitized images (`clean_image.png`)
- Recovered secret files

Created files inside this folder are ignored by Git so your data and generated images are never committed or published.
