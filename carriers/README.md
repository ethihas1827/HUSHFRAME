# Carrier Modules

This directory contains carrier-specific steganographic embedding and extraction implementations:
- `bmp_lsb/`: 24-bit uncompressed BMP spatial LSB with scanline padding preservation.
- `png_lsb/`: PNG carrier with standard LSB and adaptive texture complexity embedding.
- `jpeg_dct/`: JPEG DCT coefficient frequency embedding (Phase 2).
- `heic_container/`: HEIC container box and metadata embedding (Phase 3).
