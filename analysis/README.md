# Analysis & Steganalysis

This directory contains image quality distortion analysis and steganalysis tools:
- `psnr.c`: Peak Signal-to-Noise Ratio (PSNR) calculation.
- `ssim.c`: Structural Similarity Index Measure (SSIM) approximation.
- `histogram.c`: Channel histogram distribution variance.
- `rs_analysis.c`: Regular/Singular (RS) steganalysis detector.
- `report.c`: Analysis summary reporting.
